# Concept Medical — Engagement Request & Approval Designs

Design prototypes for the **Conference / Event / Sponsorship Request** workflow, in the Concept Medical design system.

## What's here

| File | What it is |
|---|---|
| `Conference Event Sponsorship Request (standalone).html` | The request form — 8 tabs: overview, process flow, structure, live form wizard, validation rules, Salesforce mapping |
| `Approval Workflow Screens (standalone).html` | Reviewer Console — dedicated approval screens for all 6 personas (Reporting Manager, Marketing/Product Head, Regulatory Affairs, Compliance/Legal, Finance, Business Head) |

Both files are **fully self-contained** — no build step, no server, no dependencies. Open them directly in any browser, or view via the links below.

## How to review

1. Open either HTML file in your browser (double-click works).
2. In the **Reviewer Console**, use the left rail to switch between approval personas — each sees a tailored review screen. Approving a stage advances the request to the next reviewer.
3. In the **Request form**, the "Form" tab is a working wizard with live conditional logic and budget-tier routing.

> These are interactive prototypes for design review only — no data is saved or sent anywhere.

## Keeping this private / non-indexable

- Keep this repository **Private** and invite reviewers as collaborators (Settings → Collaborators), **or**
- Host as a **secret gist** — excluded from search engines and GitHub search; only people with the URL can view.
